# AI Agent 应用架构设计 · 工作汇报

一套纯静态前端材料，用来讲解企业级 Agent 架构。页面按汇报顺序组织口径，五张架构图为可单独下载的 SVG。

图由原始手机截图重绘而成，已去掉状态栏、底部黑边和相册操作条。直接用浏览器打开即可投屏，无需安装依赖或构建。

## 打开方式

双击 `index.html`，或在本目录启动任意静态服务：

```bash
python -m http.server 4178
```

然后访问 `http://127.0.0.1:4178/`。

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 汇报页：主线、每张图的讲法、十分钟时间分配、落地检查项 |
| `css/report.css` | 页面样式 |
| `js/report.js` | 侧栏当前位置高亮 |
| `svg/` | 五张可单独打开或插入幻灯片的架构图 |

## 架构图

| 文件 | 内容 |
|---|---|
| `svg/01-value-architecture.svg` | 业务价值总览：五层、安全合规、价值交付、进化闭环 |
| `svg/02-methodology.svg` | 架构方法论：5 层 + 2 个横切 + 3 条系统流 + 1 个闭环 |
| `svg/03-fault-diagnosis.svg` | 故障诊断地图：现象与五步排障 |
| `svg/04-ten-boundaries.svg` | 十大边界 |
| `svg/05-decision-tree.svg` | 从业务目标出发的选型决策树 |

主线可以记成一句：五层向上交付价值，两侧横切约束风险，三条流把系统跑起来，十条边界划清责任，一棵决策树决定技术路径。

本目录是独立静态页，不经过网关，也不涉及登录或业务接口。
